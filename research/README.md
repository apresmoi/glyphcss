# Research

Exploratory research for glyphcss and adjacent ideas. One direction per folder —
see [`CLAUDE.md`](./CLAUDE.md) for the rules and structure. Start a new one with the
`/new-research` skill.

## Directions

| Direction | Goal | Status |
|---|---|---|
| [images-to-3d](./images-to-3d/) | Turn photos of an object into a 3D mesh — as tiny and faithful as possible, ideally in-browser — to feed glyphcss | exploring |
| [contour-first-text](./contour-first-text/) | Should outline modes (ink, braille) build contour geometry directly for text instead of reusing the fill-triangulated mesh? | exploring |
