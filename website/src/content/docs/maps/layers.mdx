Terrain, elevation contours and country borders share one map. Layers form an ordered list; geometry also uses depth testing.

## Add, move, remove

```ts
const id = map.addLayer({ type: "line", source: borders, color: "#ff9e64" });
map.moveLayer(id);              // move to the end
map.removeLayer(id);
```

Every layer accepts an optional `id`. `addLayer(layer, beforeId)` inserts before another layer; `moveLayer(id, beforeId)` reorders it.

| Type | Data / key options |
|---|---|
| `background` | `color`, `density`; no source |
| `raster` | Elevation tile or provider; `classifier`, `colors` |
| `contour` | Field or elevation provider; `levels`, `labels` |
| `line` | Vector lines; `color`, `padCells` |
| `fill` | Vector polygons; `color`, `colorProperty`, `colors`, `drape` |
| `fill-extrusion` | Vector buildings; `heightProperty`, `height`, `heightScale` |
| `symbol` | DOM text labels; `textProperty`, `priorityProperty` |
| `circle` | DOM dots; `radius`, `radiusProperty`, `radiusScale`, `color` |
| `glyph` | Points and labels in copied text; `size`, `ramp`, `textProperty` |
| `heatmap` | Density relief; `radius`, `weightProperty`, `colors`, `bounds`, `height`, `threshold` |
| `model` | Your `polygons` and `attribution`; no source |

## Sources

```ts
const cities = {
  features: [{
    geometryType: "point" as const,
    rings: [[[-58.38, -34.6]]],
    properties: { name: "Buenos Aires" },
  }],
};
map.addLayer({ type: "glyph", source: cities, textProperty: "name", color: "#ff9e64" });
```

Vector layers accept a `GlyphMapVectorFeatureCollection` or `GlyphMapVectorProvider`. Static features use `geometryType` (`"point"`, `"line"`, `"polygon"`) and `rings`; polygon hole groups use `polygons`. Add `attribution` to the collection to include its credits.

Provider layers can select `sourceLayer`; all vector layers accept `filter: (feature) => boolean`, applied after source-layer selection. Without terrain or a custom `groundElevation`, features sit on the datum.

## Raster

```ts
map.addLayer({
  type: "raster", source: reliefProvider,
  classifier: GlyphMapClassifiers.etopo1V1, colors: terrainColors,
  minElevation: 0, density: 2,
});
```

`colors` supplies one colour per classifier band. Optional `minElevation` / `maxElevation` flatten terrain outside a metre window; colours retain the original elevations. `padCells` keeps nearby provider tiles mounted. See [terrain](/maps/terrain/).

## Contour

```ts
map.addLayer({
  type: "contour", source: reliefProvider,
  levels: { interval: 500 }, minElevation: 0,
  color: "#ffe8b8", labels: true, labelEvery: 5,
});
```

`levels` accepts a count, an explicit elevation array, or `{ interval }` in metres. Intervals stay fixed while panning. Elevation windows clip contours independently of terrain; match their floors. Labels default off; `labelEvery` defaults to `5`. `getContourFieldRange(id)` reports the data range.

## Fill

```ts
map.addLayer({ type: "fill", source: regions, color: "#4a5a3a", drape: "flat" });
```

`drape: "surface"` (default) follows terrain; `"flat"` keeps a datum overlay. A predicate can choose per feature. For OSM water, use `glyphMapOpenMapTilesWaterDrape`: ocean flat, lakes draped. `colorProperty` plus `colors` maps property values to colours.

## Fill-extrusion

```ts
map.addLayer({
  type: "fill-extrusion", source: osm, sourceLayer: "building",
  heightProperty: "render_height", baseOffsetProperty: "render_min_height",
  height: 8, heightScale: 1, color: "#8a8f9c",
  colorVariation: 0.5, facade: true,
});
```

Heights and base offsets are true metres above terrain, exempt from terrain exaggeration. `height` is the fallback; `heightScale` multiplies height. `facade` and `colorVariation` default off. See a [live street view](/maps/openstreetmap/).

## Labels and point marks

```ts
map.addLayer({
  type: "symbol", source: cities, textProperty: "name",
  textAnchor: "left", textOffset: [1, 0], color: "#ffe8b8",
});
```

- `symbol` labels points and lines, not polygons; `text(feature)` composes labels.
- `priorityProperty` / `minPriority` control decluttering; labels wrap at 20 characters, up to three lines.
- `textAnchor` defaults to `"center"`; `textOffset` defaults to `[0, 0]`, in cells with y down.
- `glyph` uses `size` / `sizeProperty` / `sizeScale` in cell rows; default `size: 0` is one cell, with ramp `["·", "•", "●"]`.
- Glyph `altitude` / `altitudeProperty` / `altitudeScale` use true metres above ground; `onSelect(feature)` handles selection.
- Use `symbol` / `circle` for DOM interaction; `glyph` marks and labels survive copying the text.

## Per-layer appearance

| Option | Applies to | Effect |
|---|---|---|
| `density` | All layers | Mesh detail; strokes at `1` or omitted follow the surface grid, other values use an independent grid |
| `renderMode` | Mesh layers | Override scene mode; a different mode costs an extra pass |
| `glyphPalette` | Mesh layers | Override the character ramp independently of colours; a different ramp costs an extra pass |

Mesh layers are `raster`, `fill`, `fill-extrusion`, `heatmap`, and `model`.

## Markers

```ts
const marker = map.addMarker({ at: [-58.38, -34.6], label: "Buenos Aires", elevation: 30 });
marker.remove();
```

Markers are individual DOM elements, separate from layers. `marker.el` exposes the element. `elevation` defaults to `0`, passes through the projection's elevation axis, and does not automatically follow terrain.
