Import 3D constructors from `@glyphcss/charts/3d`. All five mark families can render headlessly with `renderGlyphChart3d(mark, options)`; the examples below are build-time monospace text, not images.

```sh
npm install @glyphcss/charts glyphcss
```

## Surface

`glyphChartSurface({ z: number[][] }, channels?, options?)` takes a row-major grid. It also accepts long records with x/y/z field channels. Grid channels can supply x column positions and y row positions.

This illustrative request-load surface samples eight hours across seven days; heights are thousands of requests.

```ts
import { glyphChartSurface, renderGlyphChart3d } from "@glyphcss/charts/3d";
const mark = glyphChartSurface(
  {
    z: [
      [0.6, 0.5, 0.9, 1.6, 2.0, 1.7, 1.2, 0.8],
      [0.7, 0.6, 1.1, 1.9, 2.4, 2.0, 1.4, 1.0],
      [0.9, 0.8, 1.4, 2.4, 3.0, 2.6, 1.8, 1.2],
      [1.1, 0.9, 1.6, 2.9, 3.6, 3.1, 2.2, 1.4],
      [1.0, 0.8, 1.4, 2.6, 3.2, 2.7, 1.9, 1.3],
      [0.8, 0.6, 1.2, 2.1, 2.6, 2.2, 1.6, 1.0],
      [0.7, 0.6, 1.0, 1.8, 2.2, 1.9, 1.3, 0.9],
    ],
  },
  { x: [0, 3, 6, 9, 12, 15, 18, 21], y: [1, 2, 3, 4, 5, 6, 7] },
  {
    axes: {
      x: { title: "Hour", ticks: 3 },
      y: { title: "Day", ticks: 3 },
      z: { title: "k req", ticks: 3 },
    },
  },
);
const result = renderGlyphChart3d(mark, {
  target: "web",
  charset: "braille",
  style: "wireframe",
  color: "css",
  width: 72,
  height: 28,
  camera: { rotX: 30, rotY: 145 },
});
```

## Scatter

`glyphChartScatter3d(records, channels?, options?)` defaults to x/y/z fields. Optional channels are categorical `series`, continuous `color` (mutually exclusive with series), and numeric `size`. `markerSize` controls the base object-space marker half-size.

```ts
import { glyphChartScatter3d } from "@glyphcss/charts/3d";
const mark = glyphChartScatter3d(
  [
    { x: 1, y: 1, z: 1 },
    { x: 2, y: 3, z: 2 },
    { x: 3, y: 2, z: 4 },
    { x: 4, y: 4, z: 3 },
    { x: 5, y: 3, z: 5 },
    { x: 6, y: 5, z: 4 },
  ],
  {},
  { markerSize: 0.18, axes: { x: { ticks: 3 }, y: { ticks: 3 }, z: { ticks: 3 } } },
);
```

## Parametric surfaces

`glyphChartParametric3d({ x, y, z, value? }, options?)` takes equally shaped coordinate grids. The optional value grid drives color independently of z. `wrapU` joins the last column to the first; `wrapV` joins the last row to the first.

```ts
import { glyphChartParametric3d } from "@glyphcss/charts/3d";
const mark = glyphChartParametric3d({
  x: [
    [-1, 0, 1],
    [-1, 0, 1],
    [-1, 0, 1],
  ],
  y: [
    [-1, -1, -1],
    [0, 0, 0],
    [1, 1, 1],
  ],
  z: [
    [0, 1, 0],
    [1, 0, 1],
    [0, 1, 0],
  ],
});
```

For curved examples, `glyphChart3dSphereGrid(radius?, rows?, cols?)` and `glyphChart3dTorusGrid(majorRadius?, minorRadius?, rows?, cols?)` generate coordinate grids. Enable the appropriate wrap options for the intended seam connections.

## Bars

`glyphChartBars3d(records, channels?, options?)` uses numeric x/y positions and z heights. Optional `xLabel`/`yLabel` channels provide labels. `barWidth` is a fraction of nearest-neighbor spacing (default 0.7).

```ts
import { glyphChartBars3d } from "@glyphcss/charts/3d";
const mark = glyphChartBars3d(
  [
    { x: 0, y: 0, z: 2 },
    { x: 1, y: 0, z: 4 },
    { x: 2, y: 0, z: 3 },
    { x: 0, y: 1, z: 3 },
    { x: 1, y: 1, z: 5 },
    { x: 2, y: 1, z: 4 },
  ],
  {},
  { axes: { x: { ticks: 2 }, y: { ticks: 2 }, z: { ticks: 2 } } },
);
```

## Line

`glyphChartLine3d(points, options?)` accepts `[x, y, z]` triples or named series `{ name?, color?, points }`. Each series needs at least two points. `glyphChart3dLorenzAttractor(steps?, dt?)` generates a longer trajectory.

```ts
import { glyphChartLine3d } from "@glyphcss/charts/3d";
const mark = glyphChartLine3d([
  [0, 0, 0],
  [1, 0, 1],
  [1, 1, 2],
  [0, 1, 3],
  [-1, 1, 4],
]);
```

## Static rendering, color, and camera

`renderGlyphChart3d` returns `text`, optional CSS `html`, `object`, `resolved`, and `report`. It uses the same headless `compileScene` pipeline as scene objects. Braille defaults to wireframe; other charsets default to solid. Explicit styles are `solid`, `wireframe`, and `ink`.

Mark options include `aspect`, `axes` (x/y/z), and `guides`. Surface, scatter, parametric, and bars support named colorscales `viridis`, `cividis`, `magma`, `greys`, or custom hex anchors, plus band counts. Line series use their own colors.

Camera render options include `rotX`, `rotY` in degrees, optional `zoom`, or a `mat` rotation matrix. Do not combine Euler rotations with a matrix. Omit zoom for auto-fit. Pass `result.resolved.camera` back as `camera` to reproduce a static frame.

## Scene objects

```ts
import { createGlyphScene, createGlyphOrthographicCamera } from "glyphcss";
import { glyphChartSurface, glyphChartObject } from "@glyphcss/charts/3d";

const host = document.querySelector<HTMLElement>("#chart")!;
const camera = createGlyphOrthographicCamera({ rotX: 30, rotY: -35, zoom: 100 });
const scene = createGlyphScene(host, { camera, cols: 80, rows: 30, mode: "solid" });
const object = glyphChartObject(
  glyphChartSurface({
    z: [
      [0, 1],
      [1, 2],
    ],
  }),
);
scene.addObject(object);
scene.rerender();
// Call scene.destroy() when this view is removed.
```

The scene renders DOM text in a `<pre>`. Mount and dispose it with your framework lifecycle, and use [controls](/components/glyph-controls/) for an interactive camera. Static charts need no mounted scene. The [chart CLI](/charts/cli/) supports surface JSON with `--3d`; the other 3D constructors use JavaScript.
