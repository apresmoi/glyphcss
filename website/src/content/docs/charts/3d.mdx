`glyphChartLine3d(points, options?)` takes `[x, y, z]` triples or named series `{ name, color, points }`. `glyphChart3dLorenzAttractor()` generates a long trajectory.

## Render options

| Option | Values |
|---|---|
| `charset` | `braille` (draws wireframe), `blocks`, `box`, `ascii` (draw solid) |
| `style` | `solid`, `wireframe`, `ink` |
| `camera` | `{ rotX, rotY }` in degrees, optional `zoom`, or a `mat` matrix; default `{ rotX: 69, rotY: 318 }` |
| `colorscale` (mark option) | `viridis`, `cividis`, `magma`, `greys`, or hex anchors |

The result carries `text`, CSS `html`, `resolved.camera` (pass it back to reproduce a frame) and `report`.

## Interactive scene

```ts
import { createGlyphScene, createGlyphOrthographicCamera } from "glyphcss";
import { glyphChartSurface, glyphChartObject } from "@glyphcss/charts/3d";

const camera = createGlyphOrthographicCamera({ rotX: 69, rotY: 318, zoom: 100 });
const scene = createGlyphScene(host, { camera, cols: 80, rows: 30, mode: "solid" });
scene.addObject(glyphChartObject(glyphChartSurface({ z: [[0, 1], [1, 2]] })));
scene.rerender();
```

`glyphChartObject` mounts any mark in a live scene; add [controls](/components/glyph-controls/) to orbit it. The [chart CLI](/charts/cli/) renders surfaces with `--3d`.
