Use `glyphChartText(data, { x, y, label })` for labels and `glyphChartRule(values, options?)` for reference lines. Rules default to horizontal (`axis: "y"`); `axis: "x"` makes them vertical.

## Label a release against a target

The example is an illustrative latency series in milliseconds. Paint the rule first, then the data and the label.

```ts
import { glyphChartLine, glyphChartText, glyphChartRule, glyphChartPlot } from "@glyphcss/charts";
const spec = glyphChartPlot({
  marks: [
    glyphChartRule([50], { name: "Target", strokeWidth: 2 }),
    glyphChartLine([42, 46, 60, 44, 38]),
    glyphChartText([{ day: 2, ms: 65, note: "Release" }], { x: "day", y: "ms", label: "note" }),
  ],
  legend: false,
});
```

Numeric-array line x coordinates start at zero. Record coordinates use the values you supply. Keep annotations within an explicit domain if they must stay visible; leave enough cells around labels and inspect render notes for fitting changes. Use `axes.x.grid` or `axes.y.grid` for repeated tick-aligned guides rather than adding many rule marks.
