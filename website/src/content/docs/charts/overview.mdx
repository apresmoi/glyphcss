`@glyphcss/charts` draws charts into a cell canvas and returns text or escaped HTML spans. Display the result in a monospace `<pre>`; no browser is needed to generate a static chart.

## Install and render a chart

```sh
npm install @glyphcss/charts
```

```ts
import { glyphChartLine, glyphChartPlot, renderGlyphChart } from "@glyphcss/charts";

const spec = glyphChartPlot({
  title: "Daily orders",
  marks: [glyphChartLine([18, 24, 21, 35, 42, 39, 48], {}, { name: "Orders" })],
});
const result = renderGlyphChart(spec, {
  target: "chat", width: 60, height: 16,
});
console.log(result.text);
```

<GlyphRender kind="chart" source={{"title": "Daily orders", "marks": [{"type": "line", "data": [18, 24, 21, 35, 42, 39, 48], "channels": {}, "options": {"name": "Orders"}}]}} options={{"target": "chat", "width": 60, "height": 16}} />

A bare number array also works: `renderGlyphChart([18, 24, 21])` creates one line mark. Use a spec when marks share axes, scales, or a title.
