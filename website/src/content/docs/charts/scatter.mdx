import GlyphRender from '../../../integrations/astro/GlyphRender.astro';

Use `glyphChartDot(data, { x, y, fill? }, options?)` for scatter plots. Braille gives sub-cell point resolution; box and ASCII use whole-cell glyphs.

## Iris measurements

This small excerpt follows the Iris dataset in the charts workbench: sepal length against petal length in centimetres. It illustrates the channel mapping, not the complete 150-flower distribution.

```ts
import { glyphChartDot, renderGlyphChart } from "@glyphcss/charts";
const result = renderGlyphChart(glyphChartDot([
  { sepal: 5.1, petal: 1.4, species: "setosa" },
  { sepal: 7.0, petal: 4.7, species: "versicolor" },
], { x: "sepal", y: "petal", fill: "species" }), { target: "terminal" });
```

Dots in the same cell may overlap. Increase width/height or aggregate dense data before rendering. There is no 2D point-size or shape option. Add [text annotations](/charts/annotations/) for selected observations, or use [3D scatter](/charts/3d/#scatter) for a third numeric coordinate.
