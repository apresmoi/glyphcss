import GlyphRender from '../../../integrations/astro/GlyphRender.astro';

`renderGlyphChartMermaid(source, options?)` supports `pie`, `xychart`/`xychart-beta`, `sankey`/`sankey-beta`, `quadrantChart`, `gantt`, `radar`/`radar-beta`, `treemap`/`treemap-beta`, `journey`, `timeline`, `packet`/`packet-beta`, and `kanban`.

Every example below is rendered at build time from the source in its collapsed disclosure. Use the [schedule and journey guide](/charts/mermaid-schedules/) and [packet and kanban guide](/charts/mermaid-structures/) for the remaining families.

```ts
import { renderGlyphChartMermaid, glyphChartFromMermaid } from "@glyphcss/charts";
const source = `pie
 "Docs": 25
 "Code": 75`;
const result = renderGlyphChartMermaid(source, { target: "chat", width: 60, height: 14 });
const spec = glyphChartFromMermaid(source);
console.log(result.text, result.report.ledger, spec);
```

## XY charts

Categories or numeric ranges drive bar and line marks. `horizontal` swaps their axes. `xychart-beta` is also accepted.

## Radar comparisons

Braille and blocks use polygon lines; box and ASCII adapt radar curves to grouped bars. `radarGrid: "outer"` keeps only the outer contour and spokes. `radarSeries: "cells"` uses whole-cell symbol edges instead of native lines.

<GlyphRender kind="chart-mermaid" source={"radar-beta\n title Delivery options\n axis speed[\"Speed\"], cost[\"Cost\"], quality[\"Quality\"], safety[\"Safety\"]\n curve hosted[\"Hosted\"] {9, 6, 7, 8}\n curve custom[\"Custom\"] {4, 8, 9, 7}\n min 0\n max 10\n graticule polygon\n ticks 2\n showLegend true"} options={{"target": "web", "width": 60, "height": 26}} />

## Adaptation and errors

Mermaid themes, browser actions, and configuration can remain inert; read `mermaid-degraded` entries for the actual replacement. `label-folded` identifies unsupported characters changed before wrapping. These are text layouts, so pixel-based Mermaid styling does not transfer directly.

Invalid source throws `GLYPH_MERMAID_SYNTAX`; a header belonging to another diagram family throws `GLYPH_MERMAID_NOT_CHART_TYPE`. Use [Diagrams](/diagrams/overview/) for flowcharts, sequences, and other node/edge syntax. The [CLI](/charts/cli/) accepts Mermaid through `glyphcss diagram`, not `glyphcss chart`.
