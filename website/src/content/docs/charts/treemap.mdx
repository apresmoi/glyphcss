Use `glyphChartTreemap(data, channels?, options?)`. Its default channels are `{ id: "id", parent: "parent", value: "value", label: "label" }`.

## Engineering allocation

These illustrative budget units form one root with three leaves. Branch totals come from children; assign magnitudes to leaves.

```ts
import { glyphChartTreemap, renderGlyphChart } from "@glyphcss/charts";
const result = renderGlyphChart(glyphChartTreemap([
  { id: "root", parent: null, label: "Engineering" },
  { id: "api", parent: "root", label: "API", value: 40 },
  { id: "web", parent: "root", label: "Web", value: 35 },
  { id: "ops", parent: "root", label: "Ops", value: 25 },
]), { target: "chat", width: 60, height: 18 });
```

Ids must be unique, parents must exist, and the hierarchy must be acyclic. Use null or an empty parent for roots. Leaves require finite, nonnegative values. Invalid hierarchy rejects with `treemap-hierarchy`.

Tiles share borders. Labels and leaf values need interior space; small tiles or whole labels that do not fit are omitted with `treemap-omitted`. Increase dimensions or aggregate tiny categories before rendering. Treemap rejects x/y scales and transforms.

For indented source syntax, see [Mermaid treemaps](/charts/mermaid/#treemap). For entity relationships rather than weighted areas, use [ER diagrams](/diagrams/er/).
