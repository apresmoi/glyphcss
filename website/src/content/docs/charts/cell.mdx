```ts
import { glyphChartCell, renderGlyphChart } from "@glyphcss/charts";
const result = renderGlyphChart({
  marks: [glyphChartCell([
    { month: "Jan", city: "Seattle", temperature: 6.0 },
    { month: "Jul", city: "Seattle", temperature: 19.5 },
    { month: "Jan", city: "Phoenix", temperature: 13.8 },
    { month: "Jul", city: "Phoenix", temperature: 35.3 },
  ], { x: "month", y: "city", fill: "temperature" })],
  scales: { x: { type: "band" }, y: { type: "band" } },
}, { target: "web", width: 60, height: 14 });
```

Cell-only plots with two band scales fit an integer grid of `2k × k` cells and can shrink the requested canvas to that grid. Unsigned heatmaps use a nonblank ramp and a range key. A signed heatmap reserves blank only for zero.

Use render option `cellRamp: [".", ":", "+", "#"]` to replace an unsigned ramp, lightest first. Signed ramps stay gain/loss ramps. Mark `options.color` sets one ink color or `[lossColor, gainColor]`; it does not replace the numeric fill channel. See [targets and colors](/charts/targets/).
