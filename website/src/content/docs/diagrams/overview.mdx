`@glyphcss/diagrams` turns Mermaid source and JSON data into monospace text.
It measures labels, lays out nodes, routes connections, and paints character cells.
It needs no scene, canvas element, or WebGL context.

## Install and render a flowchart

```sh
npm i @glyphcss/diagrams
```

```ts
import { renderGlyphDiagram } from "@glyphcss/diagrams";

const result = await renderGlyphDiagram(
  `flowchart LR
 Push[Push commit] --> Build[Build app]
 Build --> Test{Tests pass?}
 Test -->|yes| Stage[Deploy staging]
 Stage --> Smoke[Smoke tests]
 Smoke --> Prod[Deploy prod]
 Test -->|no| Fix[Fix build]`,
  { target: "chat", width: 72, height: 19, overflow: "expand" },
);
console.log(result.text);
```

## Choose a target

Targets set default cell budgets, character sets, and color encodings.
A cell is one monospace character position; width counts columns and height counts rows.
These previews use explicit compact sizes and `color: "none"` so terminal escape codes do not appear in HTML.

| Target | Default columns × rows | Charset | Color |
| --- | --- | --- | --- |
| `chat` | 72 × 24 | `box` | `none` |
| `terminal` | 80 × 24 | `braille` | `truecolor` |
| `web` (API default) | 96 × 32 | `braille` | `css` |

## Choose the entry point

| Input | Import and function |
| --- | --- |
| Mermaid graph families, including gitGraph; JSON graph | `@glyphcss/diagrams`: `renderGlyphDiagram` |
| Mermaid sequence; JSON sequence | `@glyphcss/diagrams/sequence`: `renderGlyphSequence` |
| JSON lane DAG; git-log text | `@glyphcss/diagrams/lanes`: `renderGlyphLaneDag` |

Every renderer returns `text`, optional `html`, `pages`, `meta`, and `report`.
The **fidelity report** describes adaptations made while reading and fitting the source.
Its `ledger` is a list of `{ code, message, detail? }` entries. Read it when labels,
shapes, or panel boundaries differ from your source.
