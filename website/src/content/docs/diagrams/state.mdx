## Syntax and limits

- `[*]` becomes a point marker scoped to its region; transitions use `-->` with an optional `: caption`.
- `state Choice <<choice>>` draws a diamond. Fork/join declarations use rounded nodes and report the adaptation.
- `state Name { ... }` encloses a composite. `--` separates concurrent regions; empty regions are omitted and reported.
- Notes become text rows. Invalid notes and concurrency separators have named errors in [troubleshooting](/diagrams/troubleshooting/).
- Composite transitions attach to the group's start/first or end/last child. Self-transitions on composites are adapted and reported.
- Reused state identities across scopes may need copies; inspect `state-shared`. Styling and nested directives do not execute.
