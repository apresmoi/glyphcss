## Syntax and limits

- Use `Person`, `System`, `Container`, and `Component` declarations with the appropriate header. External variants add an external marker.
- Database variants draw cylinders; queue variants draw rectangles. Person nodes use rounded outlines.
- `Enterprise_Boundary`, `System_Boundary`, `Container_Boundary`, and `Deployment_Node` enclose related nodes where supported.
- `Rel` and its directional variants create edges; dynamic relationships retain order in their labels.
- Index, style, layout, title, and asset directives are inert and reported. Set a rendered title through the API's `title` option.
- C4 captions often need a wider or taller budget. The fitter protects words and captions before gutters; an explicit direction takes precedence over automatic C4 orientation.
