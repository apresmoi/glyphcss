## Syntax and limits

- Declare `service id(icon)[Label]`, `group id(icon)[Label]`, and membership with `in groupId`.
- Connections use side prefixes such as `api:R --> L:db`. The first source side guides the initial layout direction.
- Junctions become `+` nodes. Database icons become tags such as `[db]`; external icon assets do not load.
- Port sides, alignment, group-edge attachment, and self-loops are approximated where needed and recorded in the report.
- The result is a text graph, so icon artwork and exact Mermaid positioning are not preserved. Use explicit [direction and cell budgets](/diagrams/options/) to tune it.
