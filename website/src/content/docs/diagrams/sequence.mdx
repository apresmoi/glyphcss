## Syntax and limits

- Participant aliases use `participant API as Order service`; `actor` draws a stick figure.
- Message endpoints control direction; solid and dashed message styles remain distinct. Self-messages draw a loop.
- `loop`, `alt`/`else`, `opt`, `par`/`and`, `critical`/`option`, and `break` create frames with matched `end` statements.
- Notes can sit over participants or left/right of one participant. `autonumber` supports start and step.
- Activations, `rect`, and participant `box` styling are inert. Create/destroy syntax becomes full lifelines; half and central arrows become solid or dashed directed messages with notes in the report.
- Pagination follows time and repeats participant headers and continuing frames. `overflow: "expand"` grows the height; too many participants can still produce `sequence-layout-overflow`.
- See [sequence JSON](/diagrams/json/#sequence-json) for direct control over frames and note positions.
