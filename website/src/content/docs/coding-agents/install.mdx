### Cursor, OpenCode, and other hosts

```sh
test -d glyphcss-diagrams/.git || git clone https://github.com/apresmoi/glyphcss-diagrams.git
cd glyphcss-diagrams
node install.mjs --provider grok
```

- Other providers: `cursor`, `opencode`, `agents`, `codex`, `claude`; Antigravity: `agy` (CLI), `antigravity` (IDE).
- For custom destinations, replace `--provider grok` with `--dest /absolute/path/to/skills`.
- Append `--copy` to avoid symlinks; symlink installs require the checkout to stay put.

[Directories, updates, and removal](https://github.com/apresmoi/glyphcss-diagrams/blob/main/docs/installation.md).

## 3D CLI skill

```sh
npm i -g @glyphcss/compile
mkdir -p .claude/skills/glyphcss
curl -sS https://glyphcss.com/skill.md -o .claude/skills/glyphcss/SKILL.md
glyphcss cube --auto-center
```

Claude Code: run in your project. Other hosts: place [SKILL.md](/skill.md) at `glyphcss/SKILL.md` in their skill directory. Bundled copy: `node_modules/@glyphcss/compile/SKILL.md`.

Without a global installation:

```sh
npx @glyphcss/compile cube --auto-center
```

## Troubleshooting

- **No trigger:** start a new session; check the host lists `glyphcss-diagrams`; name it explicitly.
- **Wrapping:** request fewer columns; split without losing values or connections. See [sizing](/diagrams/options/).
- **Misalignment:** request `--charset ascii` or `box`. Use monospace; web embeds need `white-space: pre` and `line-height: 1`; chat must omit ANSI escapes.
