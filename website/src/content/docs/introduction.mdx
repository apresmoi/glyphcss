## The actual DOM output

```js
import { cubePolygons } from "@glyphcss/core";
import { compileScene, createGlyphOrthographicCamera } from "glyphcss";

const { html } = compileScene({
  polygons: cubePolygons({ center: [0, 0, 0], size: 1 }),
  camera: createGlyphOrthographicCamera({ rotX: 60, rotY: 30, zoom: 200 }),
  cols: 20, rows: 9, mode: "solid", useColors: false,
});
document.body.insertAdjacentHTML("beforeend", html);
```

Rendered HTML, blank margins omitted:

```html
<pre class="glyph-output">
        %%@%%
     %%%%%%%%%%@
     %%%@%%%@@@@
     %%%%%%%@@@@
     %@%%%@%@@@@
        %%%%@
</pre>
```

Use a monospace font and `line-height: 1`. Scenes update on changes; static output needs no JavaScript.
