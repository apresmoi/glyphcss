This bundled apple loads from GLB and fits the viewport. Drag to orbit; switch to wireframe or ink. Code includes the asset URL and camera settings.

## Supported formats

| Format | Parser | Notes |
|---|---|---|
| OBJ | `parseObj(string)` | Optional MTL materials |
| glTF / GLB | `parseGltf(ArrayBuffer)` | Embedded textures supported |
| VOX | `parseVox(ArrayBuffer)` | MagicaVoxel palette colors |
| STL | `parseStl(ArrayBuffer)` | Binary or ASCII; no colors |

These parsers live in `@glyphcss/core`. `loadMesh` detects the format and returns polygons plus texture/animation data.

## Loading yourself

```ts
import { loadMesh } from "glyphcss";
const model = await loadMesh("/gallery/glb/apple.glb");
const mesh = scene.add(model.polygons);
// On teardown:
mesh.dispose();
model.dispose?.();
```

Use your own asset URL. Recenter with `recenterPolygons` or the binding's `autoCenter`; choose camera zoom for its world-unit size. For built-in and procedural geometry, see [creating shapes](/guides/creating-shapes/).
