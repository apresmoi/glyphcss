The agent replies with rendered text in a code block.

## Choose a skill

- **[glyphcss-diagrams](https://github.com/apresmoi/glyphcss-diagrams):** diagrams, sequences, git branches, and data charts in chat; renderers included.
- **[glyphcss](/skill.md):** 3D meshes and shapes through the CLI. Both skills can coexist; name the one you want.

## Render 3D with the CLI skill

| Request | Command |
| --- | --- |
| Cube | `glyphcss cube --auto-center` |
| Model preview | `glyphcss model.glb --auto-center` |
| Rotated torus | `glyphcss torus --rot-x 60 --rot-y 30 --auto-center` |
| HTML export | `glyphcss model.obj -f full -o out.html` |

[Install the 3D skill and CLI](/coding-agents/install/#3d-cli-skill). Inputs: `.obj`, `.glb`, `.gltf`, `.vox`, `.stl`, primitives, or polygon JSON. Terminals default to truecolor ANSI; pipes to plain text. Use `-f text` to disable color.

See [CLI options](/guides/compile/), [diagram examples](/diagrams/flowcharts/), [charts](/charts/bar/), or [troubleshooting](/coding-agents/install/#troubleshooting).
