Use `glyphcss-diagrams` for charts and diagrams in your agent's reply. Use the
`glyphcss` CLI skill for 3D meshes and primitive shapes in the terminal.

## Choose a skill

| Skill | Use it for | Source and requirements |
| --- | --- | --- |
| `glyphcss-diagrams` | Workflows, request sequences, git branches, and charts from data or Mermaid | [glyphcss-diagrams repository](https://github.com/apresmoi/glyphcss-diagrams); one skill with bundled renderers; Node.js 22+ |
| `glyphcss` | Previewing 3D mesh files, shapes, or custom polygons as ASCII | [skill.md](/skill.md), also bundled in `@glyphcss/compile`; runs the `glyphcss` CLI |

[Install for your host](/coding-agents/install/), then start a new agent session.
Both skills can coexist: name the one you want when a request could mean either.

## What comes back

The diagrams skill runs its bundled renderer and pastes the text into the reply,
preserving spaces inside a code block. These examples are rendered at build time
with the same Glyphcss libraries; the data and history are illustrative.

## Render 3D with the CLI skill

[Install the 3D skill and CLI](/coding-agents/install/#3d-cli-skill) for requests like these:

| You ask | The agent runs |
| --- | --- |
| “Render a cube in the terminal.” | `glyphcss cube --auto-center` |
| “Show me this model as ASCII.” | `glyphcss model.glb --auto-center` |
| “Render a torus, rotated.” | `glyphcss torus --rot-x 60 --rot-y 30 --auto-center` |
| “Save this model as an HTML page.” | `glyphcss model.obj -f full -o out.html` |

Input can be a mesh file (`.obj`, `.glb`, `.gltf`, `.vox`, `.stl`), a primitive
shape, or custom polygons as JSON. Interactive terminals default to truecolor
ANSI; piped output defaults to plain text. Ask for `-f text` when color is unwanted.

The [Compiling to Static guide](/guides/compile/) covers the CLI, Vite plugin,
and Node API. For skill discovery, narrow panes, and fonts, see
[installation troubleshooting](/coding-agents/install/#troubleshooting).
