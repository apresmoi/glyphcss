# Shape gallery

Every built-in geometry, rendered by glyphcss's `ink` mode via the compile CLI:

```bash
npx @glyphcss/compile <shape> --mode ink --fit 52 --cell-aspect 2.3 --no-colors -f text
```

(`--cell-aspect 2.3` matches GitHub / VS Code markdown code-block metrics; terminals are nearer 2.0.)
